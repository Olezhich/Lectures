# Конституция
Все граждане РФ могут учавствовать в выборах
Каждый имеет право на свободное сипользование своего имущества для предпринимательскаой деятельности 
Никто не может быть лишен своего имущества никак кроме как по решению суда
Трудоспособные дети, достигшие 18 лет должны заботиться о нетрудоспособных родителях (это пенсионеры, инвалиды)
